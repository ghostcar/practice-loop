# PQ-006 — Рейт-лимиты и лимиты расходов

## Вопрос

Какой механизм рейт-лимитов и лимитов расходов при открытии доступа другим пользователям?

## Контекст

Отложено (legacy Q6). ADR-012: «рейт-лимиты — отложено».

## Решение

Не принято. Решать при открытии доступа другим пользователям.
