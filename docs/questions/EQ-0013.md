# EQ-0013 — OCR/LLM-распознавание одноразовых кодов по фото

## Вопрос

Внедрять ли OCR/LLM-распознавание verification-кода по загруженной фотографии?

## Контекст

`verification_challenges` реализованы (HMAC-SHA256, constant-time, TTL, max attempts) — это ручная
верификация. OCR/LLM-распознавание отложено (legacy Q13, три места: `app/models/media.py`,
`app/services/media.py`, `app/api/verification.py`).

## Инвариант

LLM не источник истины для кода (PD-014) — допустим только как подсказка; финальная верификация
остаётся constant-time HMAC.

## Решение

Не принято. Решать при предметной обвязке Chastity Timer (Этап 3) или отдельным решением владельца.
