# EQ-0013 — OCR/LLM-распознавание одноразовых кодов по фото

## Вопрос

Внедрять ли OCR/LLM-распознавание verification-кода по загруженной фотографии?

## Контекст

`verification_challenges` реализованы (HMAC-SHA256, constant-time, TTL, max attempts) и остаются
источником истины. OCR-first распознавание уже реализовано для seal/media-потока по ADR-181:
локальный `pytesseract` используется перед LLM-vision, а низкая уверенность уходит в fallback/manual review.
OCR именно кодов лекарств остаётся отдельным, не принятым расширением.

## Инвариант

LLM не источник истины для кода (PD-014) — допустим только как подсказка; финальная верификация
остаётся constant-time HMAC.

## Решение

Принято по ADR-181: OCR-first для seal/media verification, LLM-vision как fallback, HMAC как
авторитетная финальная проверка. Вопрос о medication-specific OCR остаётся отдельным backlog item.
