# EQ-0014 — LockTimer penalty не проброшен в HTTP

## Вопрос

Как привязать `apply_penalty` к HTTP-путям? Сейчас penalty реализован в домене, но не вызывается
ни одним HTTP-эндпоинтом (`lock_penalty_events` = 0 на проде).

## Контекст

`apply_penalty` (ADD_TIME / BLOCK_NEXT_SLOT / MARK_TASK_FAILED / POINTS, идемпотентность, cap по
`max_end_at`) покрыт сервисными тестами. UI «Skip this task? Penalty may apply» вводит в заблуждение —
skip не накладывает penalty.

## Решение

Требует продуктового решения: тип/размер penalty по умолчанию, затем — привязка к `skip_task`/late-close
через `rule.penalty_policy` или отдельный эндпоинт.
