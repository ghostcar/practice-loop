# ADR-164 — Service Layer Extraction — journal.py → journal_service.py

**Decision:** Extract all business logic from `app/api/journal.py` (1117 lines) into `app/services/journal_service.py` (987 lines), leaving `journal.py` as thin HTTP wrappers (313 lines).

**What moved to service:**
- Timer bridge: `ensure_timer_slot_entry`, `get_pending_slot_entry`
- Dashboard: `journal_summary`
- Queries: `media_map`, `activity_title_map`, `get_journal_page_context`
- Validators: `parse_scale`, `parse_int`, `validate_partner_id`, `validate_activity_log`, `validate_care_products`, `resolve_catalog_item`, `validate_partner`
- Entry logic: `apply_entry_fields`, `cycle_snapshot`
- CRUD: `create_entry`, `complete_entry`, `delete_entry`, `create_partner`, `delete_partner`, `attach_entry_media`
- Serializers: `entry_view`, `entry_json`
- JSON API: `json_journal_summary`, `json_create_entry`, `json_complete_entry`, `json_create_partner`, `json_delete_entry`, `json_delete_partner`, `json_analyze_partner_dynamics`
- Pydantic bodies: `EntryBody`, `CompleteBody`, `PartnerBody`

**Cross-module imports (5 files):** Re-exported from `journal.py`:
- `ensure_timer_slot_entry` → locktimer (execution, commands)
- `get_pending_slot_entry` → locktimer (commands)
- `_journal_summary` → today, dashboard

**Status:** accepted (implemented, 1380 tests green, deployed).
