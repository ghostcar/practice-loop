# ADR-205 — Локальный OCR-режим верификации таймера пояса и памятка об однозначности кода

**Date:** 2026-09-09
**Decision:** В рамках автономности, приватности и отказоустойчивости фотоверификации утверждены следующие решения:
1. **Режим локального OCR (без ИИ / на сервере):**
   - В селектор `verification_mode` наряду с `ai_vision`, `community`, `keyholder` добавлен полноценный режим `local_ocr` («Локальный OCR (Tesseract / без ИИ / на сервере)»).
   - Фотография обрабатывается встроенным сервером Tesseract OCR с адаптивной контрастной предобработкой (`app/media/ocr_seals.py`) без передачи данных во внешние облачные LLM-провайдеры, исключая риски срабатывания safety-фильтров провайдеров и сохраняя полную автономность без интернета (ADR-070, ADR-181).
2. **Контекстная памятка об однозначности кода:**
   - Для режима `local_ocr` в конфигураторе черновика и на экране активной проверки выводится явная подсказка-памятка:
     *«Для локального OCR (без нейросети) делайте код однозначным: один крупный код на чистой бумаге, либо крупно на экране часов/калькулятора. Не используйте бумагу с зачёркнутыми старыми кодами, так как линии перечёркивания создают графический шум для классического алгоритма распознавания символов.»*
3. **Принцип Добровольной Эмуляции (ADR-129):**
   - Пользователь сохраняет цифровую автономию и возможность ввода номера бирки и кода вручную при необходимости.
**Status:** ✅ принято к реализации.
