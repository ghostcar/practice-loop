# ADR-194 — Бесшовный механизм привязки Telegram-бота (1-Click Deep Link, SVG QR-код, двусторонний OTP)

**Date:** 2026-09-09
**Decision:** Для устранения любого трения при подключении мобильного Telegram-бота к аккаунту портала («Zero Friction») внедрён комплексный сервис привязки `telegram_link_service`:
1. **1-Click Deep Link (`https://t.me/<bot>?start=link_<code>`):** при переходе по ссылке из профиля или дашборда пользователь попадает сразу в Telegram-бот и при нажатии «Start» / отправке `/start` происходит мгновенное автоматическое связывание `user.telegram_chat_id = message.chat.id`, активация персонального контура и установка постоянной клавиатуры.
2. **Векторный QR-код в профиле (`/profile/telegram-qr`):** генерация чистого векторного SVG через встроенную библиотеку `zxing-cpp` без внешних зависимостей, JS и CDN. Пользователь может отсканировать QR камерой смартфона прямо с экрана компьютера и моментально привязать устройство.
3. **Двусторонний OTP:**
   - Из бота на портал: команда `/connect` или `/otp` генерирует 6-значный цифровой код со сроком действия 10 минут. Пользователь вводит этот код в форму профиля (`POST /profile/telegram-link-by-otp`) для мгновенного связывания без ручного копирования chat_id.
   - Из портала в бот: отображение 6-символьного кода в профиле для отправки команды `/link <code>` в боте.
4. **Управление привязкой в профиле:** карточка интеграции показывает текущий статус подключения, `chat_id`, кнопку перехода в Telegram и безопасную отвязку (`POST /profile/telegram-unlink` и команду `/unlink` в боте).
5. **Безопасность:** автоматическая очистка просроченных кодов, однократность использования OTP, атомарный перевод chat_id при перепривязке между аккаунтами.
**Status:** ✅ принято и реализовано.
