# ADR-176: Service Layer Extraction — protocols.py → protocols_service.py

## Context

`protocols.py` (404 lines) — protocol list/builder/run pages, steps parsing, capability checks, ownership checks, mutation wrappers.

## Decision

- `app/services/protocols_service.py` (360 lines) — constants, `parse_steps_form`, `get_own_protocol`, `require_protocol_capability`, page contexts, mutation wrappers
- `app/api/protocols.py` (230 lines, was 404) — thin HTTP wrappers + template rendering
