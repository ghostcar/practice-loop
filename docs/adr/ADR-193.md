# ADR-193 — Персональный контур Telegram-бота (One-Click, слоты лекарств, AI-генератор, тренировки, замеры, штрафы)

**Date:** 2026-09-08
**Decision:** По решению владельца («весь персональный контур заводим туда, механизмы создания только через ЛЛМ, ручные сценарии на сайте, через бота только выполнение»):
1. **Главное меню (Reply Keyboard):** постоянная клавиатура с 6 секциями (`📋 План дня`, `💊 Лекарства`, `🤖 AI-генератор`, `🏋️ Тренировка`, `❤️ Чек-ин / Замеры`, `🏆 Прогресс`), авто-подключаемая при старте (`/start`), меню (`/menu`) и успешной привязке (`/link`).
2. **План дня и выполнение (Tasks):** список задач на сегодня с 1-клик выполнением (`done:{id}`) по плановым параметрам без перехода на сайт; возможность выполнения с кастомными минутами (`task_custom:{id}`), пропуск без штрафа (`task_skip:{id}`) и прерывание со штрафом (`int:{id}`, ADR-029).
3. **Лекарства и слоты (Medications):** отображение ближайшего временного слота (утро/день/вечер/время) со сводным пакетным приёмом «✅ Принять всё (время)» (`med_slot_take:{time}`) и кнопками одиночного приёма (`med_take:{id}`). Начисление XP за дисциплину.
4. **AI-генератор:** быстрое создание персональных активностей через LLM-ассистента (`ai_gen:auto/quick/relax/intense`) и диалоговый режим с возможностью пожеланий; ручной конструктор задач оставлен на веб-сайте.
5. **Тренировки:** отображение тренировочного дня, интерактивный чеклист упражнений (`tr_toggle`), завершение дня (`tr_complete`), адаптация нагрузки под самочувствие и генерация AI-программы при отсутствии плана.
6. **Самочувствие и замеры:** быстрая фиксация настроения (1–5), энергии (1–5), запись веса через FSM диалог (`BodyMeasurement`), статус цикла.
7. **Прогресс и отработка штрафов:** баланс очков, уровень, XP, серия дней, активные квесты и кнопка отработки штрафов (`PenaltyRedemption` -> начисление очков).
8. **Маркировка и фото:** автоматическое распознавание GS1 DataMatrix (Честный Знак РФ) при отправке фото пачки с добавлением в аптечку; при отсутствии кода — автоматическая маршрутизация на мультимодальную верификацию в AI-агент.
