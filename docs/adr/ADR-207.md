# ADR-207 — Комплексная фармацевтическая экосистема (ИИ-мастер курсов, ситуативные приёмы PRN, мульти-аптечный учёт, группировка Время+Еда и авто-списание FEFO)

**Date:** 2026-09-10  
**Decision:** Утверждено расширение модуля медикаментов до комплексной фармацевтической экосистемы со следующими компонентами:

1. **Автоматическое списание остатков при приёме (FEFO Auto-Deduction):**
   - При отметке приёма (в вебе или Telegram-боте) принятая доза автоматически списывается из остатков `MedStock`.
   - Приоритет списания: принцип FEFO (First Expired, First Out — сначала партия с наиболее ранним сроком годности), с учетом предпочтительной аптечки.
   - Механизм отмены приёма (Unmark / Delete Intake) с возвратом списанного количества обратно на склад.

2. **Ситуативный приём по требованию (PRN / As-needed):**
   - Режим фиксации приёмов вне планового расписания (обезболивающие, жаропонижающие, спазмолитики).
   - Пользователь указывает: препарат, принятую дозу, причину приёма (головная боль, спазм) и **конкретную аптечку списания** (Дом, Офис, Авто/Сумка).

3. **Мульти-аптечный учёт и привязка курсов к аптечкам:**
   - Препараты могут храниться одновременно в нескольких аптечках.
   - Расписания и курсы поддерживают указание предпочтительной аптечки (`preferred_kit_id`).
   - В карточке слота и напоминании бота отображается локация: `📍 Брать из: Офис`.

4. **Группировка слотов «Время + Отношение к еде»:**
   - Внутри каждого временного слота (напр. 08:30) приёмы разделяются по режиму питания:
     - `before_meal` (до еды за 20-30 мин);
     - `during_meal` (с пищей);
     - `after_meal` (после еды);
     - `independent` (не зависит от еды);
     - `empty_stomach` (натощак).

5. **ИИ-Мастер формирования курсов (Course Wizard):**
   - Генерация медицинских и оздоровительных протоколов по свободной цели пользователя (ЗГТ с прицелом на лактацию, восстановление суставов, курс витаминов).
   - Формирование фаз, перечня препаратов, дозировок, совместимости и плана по дням с кнопкой создания курса в 1 клик.

6. **Умный ввод с чипами дозировок и бесшовные цепочки аналогов:**
   - Интерактивные чипы дозировок и форм выпуска из каталога с автоформированием названия.
   - Быстрые действия в карточках аналогов (`В справочник`, `Купить в аптечку`, `Заменить в курсе`).
   - Стратегия автоматического перехода: допить остаток оригинального препарата, затем автоматически переключить слоты на купленный аналог.

7. **Интерактивные функции Telegram-бота:**
   - Кнопки Snooze («Отложить на 15/30 минут») в уведомлениях.
   - Управление ситуативным приёмом прямо из Telegram.
