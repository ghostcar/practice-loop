# ADR-184 — Onboarding wizard

## Contract

- `none`: manual mode; the LLM step is skipped.
- `portal`: the user chooses a deployment-managed provider; the deployment key is used by the portal runtime.
- `personal`: the user configures a private BYOK provider in `/llm-configs/`.
- The selection is persisted in `user.prefs.ai_participation` when onboarding is completed.
- Portal quick-pick returns to `/onboarding?step=3&llm=saved`; arbitrary redirect targets are rejected.
- The wizard contains no inline `onclick` or `onchange` handlers because the application CSP forbids them.
