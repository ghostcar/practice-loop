# ADR-186 — Web session hardening

## Contract

- The browser never receives the refresh token hash; only the opaque cookie value travels, scoped to `/auth`.
- A refresh token is single-use: every rotation revokes the presented token and records its replacement via `rotated_from_id`.
- Logout is the only revocation entry point for web sessions; `/privacy/delete` still removes the whole account.
- `next` post-login targets must start with a single `/` (no protocol-relative `//`).
