# ADR-111 — Гендерно-инклюзивный Дневник Здоровья и Календарь Ритмов

**Decision:** По решению владельца: расширение Health & Cycle до инклюзивного комплекса с поддержкой ГТ (HRT / ZHT), эмуляции циклов (`natural_menstrual`, `hrt_emulated`, `biorhythm_custom`, `disabled`), отслеживанием post-session откликов (drop / bruising / skin sensitivity) и расчётом фаз (миграция 067). Интерактивные настройки профиля, отметки ГТ и гибкие события.
