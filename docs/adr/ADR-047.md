# ADR-047 — LockTimer: модуль, не второе приложение (D-001)

**Decision:** LockTimer живёт внутри Practice Loop как отдельный bounded context с таблицами `lock_*`, но может быть единственным включённым доменом. Никакого второго репозитория, auth, React/Vite или отдельного deployable. Один код, один Alembic head, три варианта: tracker/timer/combined

**Status:** accepted (legacy: принято)
