# ADR-175: Service Layer Extraction — calendar.py → calendar_service.py

## Context

`calendar.py` (426 lines) — availability check (used by LLM + tasks), day schedule resolution, template/window/override CRUD, page context.

## Decision

- `app/services/calendar_service.py` (323 lines) — ALL business logic including `is_available()` + `get_day_schedule()`
- `app/api/calendar.py` (207 lines, was 426) — thin HTTP wrappers + backward-compatible re-exports
- Updated 3 cross-module importers to import from service directly:
  - `app/services/dashboard_service.py` — `get_day_schedule`
  - `app/services/tasks_service.py` — `get_day_schedule`, `is_available`
  - `app/llm/context_builder.py` — `get_day_schedule`
