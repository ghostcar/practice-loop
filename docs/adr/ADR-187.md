# ADR-187 — Удаление мёртвых экспериментальных таблиц

## Contract

- Таблицы `automation_triggers`, `user_league_tiers`, `user_duels` удаляются миграцией
  `094_drop_dead_experimental`; downgrade воссоздаёт их точную схему (самодостаточные
  `op.create_table`, без зависимости от удалённых ORM-моделей).
- Модели (`app/models/{automation,community_leagues,duels}.py`), agent-движки
  (`app/agent/{automation_triggers,community_leagues,weekly_duels}.py`) и их unit-тесты удалены.
- `config.experimental_leagues` убран (не использовался вне удалённой модели).
- Emoji в i18n-строках UI (действовавшие как иконки) заменены на icon-pack: кнопки диет
  получают макрос `icon('sparkles'/'ai')`, мёртвые ключи `social_encourage` и `inv_drag_hint`
  очищены от emoji; `tests/test_icon_pack.py::test_no_emoji_icons_in_i18n` запрещает регрессию.

## Verification

- Миграция: single head `094_drop_dead_experimental`; upgrade/downgrade проверены на PostgreSQL.
- `pytest` таргетный набор (icon-pack, localization, затронутые тест-файлы) зелёный;
  `ruff check` + `ruff format --check` чистые.
- Production-таблицы перед удалением пусты (0 строк) — потери данных нет.
