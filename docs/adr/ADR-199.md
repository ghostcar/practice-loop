# ADR-199 — Перманентная заморозка и разморозка таймера сессии пояса (Permanent Freeze & Unfreeze State, события WearEventDefinition, UI и расширения)

**Date:** 2026-09-09
**Decision:** В рамках расширения механик контроля времени сессии пояса верности и каталога событий ношения утвержден механизм перманентной заморозки и разморозки таймера:
1. **Модель состояния сессии (`LockSession`):**
   - Добавлены поля:
     - `is_frozen: bool = False`: флаг текущей заморозки таймера.
     - `frozen_at: datetime | None`: момент времени наложения заморозки.
     - `frozen_remaining_seconds: int | None`: точное количество оставшихся секунд на момент заморозки.
   - При активации заморозки:
     - `frozen_remaining_seconds` фиксирует актуальный остаток времени: `max(0, int((effective_end_at - now).total_seconds()))`.
     - `is_frozen` переводится в `True`.
     - Обратный отсчет в интерфейсе останавливается; таймер больше не тикает.
2. **Механика разморозки (Unfreeze):**
   - При снятии заморозки:
     - Новое время окончания рассчитывается строго от текущего момента: `effective_end_at = now + timedelta(seconds=session.frozen_remaining_seconds)`.
     - `is_frozen` сбрасывается в `False`, поля `frozen_at` и `frozen_remaining_seconds` очищаются.
     - Обратный отсчет таймера возобновляется.
3. **Регистрация событий в каталоге ношения (`WearEventDefinition`):**
   - Добавлены два канонических определения событий ношения:
     - `timer_freeze`: «Перманентная заморозка таймера» (категория `timer`, `trigger_config: {"freeze_timer": True}`).
     - `timer_unfreeze`: «Разморозка таймера» (категория `timer`, `trigger_config: {"unfreeze_timer": True}`).
   - Каждая операция заморозки/разморозки создает синхронную запись в `wear_event_logs` с указанием причины (решение Ключника, дисциплинарное взыскание, рулетка судьбы, добровольная эмуляция) и в `lock_game_actions`.
4. **Интеграция в Chaster Extensions и Игровой контур (ADR-198):**
   - В Колесо Фортуны добавлены секторы:
     - `freeze_perm`: «❄️ Перманентная заморозка» (таймер останавливается бессрочно до выполнения условий разморозки).
     - `unfreeze`: «🔥 Разморозка таймера» (возобновление хода времени при выпадении).
   - В испытаниях послушания: успешная сдача фото-испытания при замороженном таймере автоматически снимает заморозку («Растопить ледяные оковы покорностью»).
5. **Интерфейс (UI) и Telegram-бот:**
   - В UI карточки таймера (`session_detail.html`):
     - При `is_frozen = True`: визуальный ледяной баннер с иконкой `❄️`, фиксированный замер времени, кнопка «🔥 Разморозить таймер».
     - При `is_frozen = False`: кнопка «❄️ Заморозить таймер» с модальным подтверждением.
   - В Telegram-боте в меню «🔒 Пояс» статус отражает `❄️ Таймер заморожен (ход времени остановлен)` и предоставляет кнопку быстрого управления.
6. **Принцип Добровольной Эмуляции (ADR-129):**
   - Все статусы заморозки остаются в рамках цифровой геймификации; интерфейс не блокируется, пользователь всегда сохраняет возможность нажать кнопку ручной разморозки или безопасной остановки.
**Status:** ✅ принято к реализации.
