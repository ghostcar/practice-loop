context: "LLM-vision verification (ADR-075) works but is expensive and slow for code_match. Users upload photos of seal tags; most are machine-readable codes (alphanumeric, 4-12 chars). Local OCR (pytesseract) can extract these at near-zero cost and sub-second latency. LLM-vision should be reserved as a fallback for low-confidence OCR or non-code types (chastity_closed)."
decision: "1. Add pytesseract (eng+rus) to Docker image. 2. Preprocessing: grayscale → contrast stretch ×2.5 → sharpen → adaptive binarization. 3. For code_match: try OCR first. If confidence >= 0.90, use OCR result directly (skip LLM). If OCR fails or low confidence, fall back to LLM-vision. 4. OCR timeout: 5s (ThreadPoolExecutor). On timeout → fallback to LLM. 5. Confidence threshold: 0.75 — below this, flag as low_confidence for manual review. 6. Tag pattern: regex (TAG[-_]?)?([A-Z0-9]{4,12}) with at least one digit. 7. Media vault: run OCR on upload (best-effort, never block), auto-caption with extracted tag. 8. Standalone OCR tab on /llm/verify: upload photo → extract text without LLM. 9. API: POST /api/v2/media/ocr-extract (JSON) + POST /llm/verify/ocr (form)."
