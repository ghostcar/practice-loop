# ADR-052 — Feature flags — default off (03A §7)

**Decision:** Все новые flags (LOCKTIMER_CORE_ENABLED, SOCIAL_ENABLED, etc.) default FALSE для staged rollout. APP_PRODUCT_VARIANT default combined для upgrade. Fresh deploy требует явного значения. На старте конфигурация валидируется и строится immutable ProductComposition

**Status:** accepted (legacy: принято)
