# ADR-166: Service Layer Extraction — training.py → training_service.py

## Статус

Принят, реализован.

## Контекст

`training.py` (750 строк) — монолит с бизнес-логикой, HTTP-хендлерами и вспомогательными функциями.

## Решение

- `app/services/training_service.py` (597 строк) — все CRUD, LLM-пайплайн, serializers, validators
- `app/api/training.py` (299 строк, было 750) — только парсинг форм + вызов сервиса + ответ

## Последствия

- `_render_log_entry_row` (UI-рендер) остался в training.py с re-export в тестах.
- `complete_once()` требует User object — в service делается lookup User по user_id.
- LLM-ошибки (JsonRepairError) ловятся broad `except Exception` → 303 redirect.
