# ADR-161 — Service Layer Extraction — care.py → care_service.py

**Decision:** Extract all business logic from `app/api/care.py` (1417 lines) into `app/services/care_service.py` (1161 lines), leaving `care.py` as thin HTTP wrappers (478 lines).

**Pattern:** "Thin Routes" — each HTTP handler is 3-10 lines: try → service call → except → redirect/JSON.

**What moved to service:**
- Serializers: `product_view`, `entry_view`, `routine_json`, `product_json`, `entry_json`, `course_json`
- Validators: `validate_routine`, `resolve_catalog_item`, `resolve_inventory_item`, `resolve_products`
- CRUD: `create/delete_routine`, `create/delete_product`, `create/delete_entry`, `create/delete_course`
- Join-table ops: `set_entry_products`, `set_routine_products`
- Queries: `get_care_page_context`, `get_care_summary`, `json_care_summary`, `json_list_products`, `json_list_courses`
- Pydantic bodies: `RoutineBody`, `EntryBody`, `ProductBody`, `CourseBody`
- Cycle snapshot: `cycle_snapshot`

**Cross-module imports:** Re-exported from `care.py` via `from app.services.care_service import ...`

**Error handling:** `NotFoundError` (from `app/services/errors.py`) for entity-not-found → HTTP 404; `ValueError` for validation → HTTP 400.

**Status:** accepted (implemented, 1380 tests green, deployed).
