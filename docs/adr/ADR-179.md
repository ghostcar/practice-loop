# ADR-179 — New-user bootstrap: catalog opt-in and LLM presets

**Date:** 2026-08-25
**Decision:** Коммит `8bd5515d71f0a483fb927a93d8c3c2a647dcadc3` добавил идемпотентный `_bootstrap_new_user`: при onboarding создаются системные Entity, opt-in всех публичных сущностей с neutral desire и пресеты LLM (Omniroute, Groq, OpenRouter). Это реальный decision record, поэтому номер не является пропущенным.
