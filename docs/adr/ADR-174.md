# ADR-174: Service Layer Extraction — import_data.py → import_data_service.py

## Context

`import_data.py` (493 lines) — template metadata (TEMPLATES/EXPORT_TYPES), template download, import page context, full/per-type export logic, serializers. Per-type import handlers already live in `app/api/importers/*`.

## Decision

- `app/services/import_data_service.py` (422 lines) — TEMPLATES/EXPORT_TYPES metadata, `model_to_dict`, `rows_to_csv`, `export_full_data`, `export_data_by_type`, `get_template_download`, page context
- `app/api/import_data.py` (148 lines, was 493) — thin HTTP wrappers; upload/api_push still delegate to `app.api.importers.*`

## Consequences

- Route file −70% (493 → 148 lines)
- Upload/import behavior unchanged (importers untouched)
