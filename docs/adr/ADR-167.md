# ADR-167: Service Layer Extraction — dashboard.py → dashboard_service.py

## Статус

Принят, реализован.

## Контекст

`dashboard.py` (678 строк) — монолит с контекстом дашборда, achievements, notifications, privacy, Telegram linking.

## Решение

- `app/services/dashboard_service.py` (499 строк) — queries, summaries, alerts, CRUD
- `app/api/dashboard.py` (223 строк, было 678) — тонкие HTTP-обёртки

## Последствия

- `_safe_summary()` загружает модульные summary через service-файлы напрямую.
- aftercare и insights ещё не декомпозированы — импортируются из api модулей.
