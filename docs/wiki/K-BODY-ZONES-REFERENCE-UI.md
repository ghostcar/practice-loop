# Справочник зон тела — пользовательское представление

`BodyPart.slug`, `body_system` и UUID — внутренние идентификаторы и не выводятся пользователю.
Страница `/body-parts` показывает локализованные `title_ru`/`title_en`, группирует зоны по
локализованным областям и сохраняет иерархию через вложенность списка. Чувствительность —
информационный признак и обозначается видимой текстовой меткой, а не только цветом.

Поиск сопоставляет локализованные названия и оставляет видимыми подходящую зону вместе с её
родителями. Фильтр работает по `body_system`, но показывает человеку локализованное название
группы. Пустое состояние и ошибка загрузки локализованы; на мобильном поисковое поле и фильтр
располагаются вертикально.

Регрессия закрыта статическими тестами `tests/test_body_parts_frontend.py` и browser-сценарием
в `tests/browser/portal.spec.ts`. Приёмка включает отсутствие slug-ов в видимом тексте, поиск,
фильтр, viewport 360 px, отсутствие browser errors и axe-проверку dark/light.
