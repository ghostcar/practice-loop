# Система памяти проекта (tracker)

Папка `memory/` — единое место для хранения **состояния проекта**, **принятых решений**
и **журнала сессий**. `AGENT.md` и `tracker-spec.md` описывают *как делать*; файлы здесь —
*что происходит* и *что решено*.

## Файлы

| Файл | Что хранит | Когда читать | Когда обновлять |
| --- | --- | --- | --- |
| `CONTEXT.md` | Краткий контекст проекта: что, зачем, стек, принципы, ссылки | При работе с новой областью; когда контекст «потерян» | При смене стека, принципов, ключевых ссылок |
| `STATUS.md` | Текущий статус: фазы, сделано/в работе/осталось, чек-листы | **Каждую сессию, в начале** | **Каждую сессию, в конце** |
| `DECISIONS.md` | Реестр принятых решений (ADR): решение, контекст, альтернативы | При работе над затронутой областью | **Сразу после принятия решения** (в тот же момент) |
| `SESSIONS.md` | Журнал сессий: дата, тема, что обсуждали, результаты | При необходимости восстановить историю | **Каждую сессию, в конце** |
| `OPEN_QUESTIONS.md` | Открытые вопросы и отложенные решения | **Каждую сессию, в начале** | При появлении/закрытии вопросов |
| `CHANGELOG.md` | История изменений файлов проекта | При сомнениях «что и когда менялось» | После каждого существенного изменения файлов |

## Обязательные правила

1. **В начале каждой сессии** прочитать: `README.md`, `STATUS.md`, `DECISIONS.md`,
   `OPEN_QUESTIONS.md` (плюс `CONTEXT.md`, если работа идёт с новой областью).
2. **В конце каждой сессии** обязательно обновить: `SESSIONS.md` (запись о сессии)
   и `STATUS.md` (актуальное состояние). Если принимались решения, менялись открытые вопросы
   или файлы проекта — обновить `DECISIONS.md`, `OPEN_QUESTIONS.md`, `CHANGELOG.md`.
3. **Не дублировать** содержимое `AGENT.md` и `tracker-spec.md` в memory-файлах —
   ссылаться на них.
4. **Фиксировать сразу:** решение, принятое в середине сессии, записывается в `DECISIONS.md`
   в тот же момент, а не «потом, в конце».
5. Записи короткие и точные: факты, решения, ссылки. Без воды.
6. Статусы решений: `принято` / `отложено` / `отклонено`.
