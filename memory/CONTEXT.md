# Контекст проекта (practice-loop)

## Что это
Веб-приложение для отслеживания и управления активностями в личных/парных отношениях
(только для взрослых, по обоюдному согласию). Каталог задач, сессии, история, геймификация
(XP, уровни, достижения), штрафы, LLM-подбор задач.

## Состояние
- Проектирование **завершено**, код написан (11 фаз, см. `STATUS.md`).
- Пройден аудит v0.7 (`REMEDIATION_SPEC.md`), проведено интервью по ключевым решениям (ADR-029–034).
- Текущий фокус: стабилизация v0.7 (R0→R1 из REMEDIATION_SPEC.md).

## Стек
- Backend: Python 3.11+, FastAPI (async), Pydantic v2, Uvicorn.
- DB: PostgreSQL 15, SQLAlchemy 2.0 (async), Alembic.
- Frontend: Jinja2 (SSR) + HTMX + TailwindCSS. i18n EN/RU (расширяемо), темы dark/light.
- LLM: `openai` SDK (OpenAI-совместимые endpoints), BYOK. Провайдеры: **Omniroute** (локальный,
  активен по умолчанию), Groq, OpenRouter.
- Telegram: **aiogram 3.x** (вебхук, интерактивный).
- Деплой: Docker Compose (app, PostgreSQL, Nginx + SSL) на VPS; бэкапы pg_dump по cron.
- Тесты: pytest, unit + интеграционные.

## Ключевые принципы
1. **Гибридная генерация:** LLM выбирает задачу из каталога, осознанно одобренного пользователем.
2. **Комплаенс:** никакого обхода safety-фильтров провайдеров (ADR-001).
3. **Приватность:** экспорт/удаление данных, обезличенная доска достижений.
4. **Масштабируемость:** сейчас один пользователь, но модель данных сразу мультипользовательская
   (совместные сессии, публичный каталог с авторством).

## Соглашения по дате/времени
- Всё хранится в UTC (`DateTime(timezone=True)`); prod=Postgres aware, tests=SQLite naive → `as_utc()`.
- Отображение — в tz устройства: Jinja `localtime()` + JS `applyLocalTimezones()`.
- Границы суток — device-local: cookie `client_tz` → ContextVar → `local_today()`/`local_date()`.
